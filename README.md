# ONE SMALL CHOICE

**小さな選択が、世界を変える。**

日常のなにげない行動が、人から人へ、地域から国へ、そして地球全体へと広がっていく。
バタフライエフェクト（小さなことが大きな変化を生む現象）をテーマにした、ブラウザで遊べるシミュレーションゲームです。

---

## あそびかた

1. **START** を押す
2. 日常の場面を読んで、**自分の行動を選ぶ**
3. 世界が自動で動きだす。出来事が線でつながり、「個人 → 周囲 → 地域 → 国 → 世界」へ広がっていく
4. 途中で何度か、また選択の場面が来る（1回のプレイで3回）
5. 最後に **何年後かの地球** が表示される
6. **選ばなかった未来** と見くらべる
7. **ANOTHER FUTURE** で、最初の選択を変えてもう一度

- シミュレーション中は、画面をタップすると次の出来事へ進みます
- 下のボタンで速さ（0.5× / 1× / 2×）を変えたり、**SKIP** で一気に進めたりできます
- 1回のプレイは約5分です

## パソコンで遊ぶには

1. このフォルダの中にある **`index.html`** をダブルクリックします
2. ブラウザ（Chrome、Safari など）でゲームが開きます

インターネットにつながっていなくても遊べます（つながっていると、文字がよりきれいな書体で表示されます）。

## スマホで遊ぶには（GitHub Pages で公開する）

GitHub の「Pages」という無料の機能を使うと、ゲームにURL（インターネットの住所）がつき、iPhone からも遊べるようになります。

1. GitHub でこのリポジトリのページを開く
2. 上のほうにある **Settings**（歯車のマーク）を押す
3. 左のメニューから **Pages** を押す
4. 「Branch」のところで、ゲームが入っているブランチ名を選び、フォルダは **/(root)** を選んで **Save** を押す
5. 1〜2分待ってページを再読み込みすると、上のほうに `https://〜.github.io/〜/` というURLが表示されます
6. そのURLを iPhone の Safari で開けば遊べます（「ホーム画面に追加」するとアプリのように使えます）

## 記録について

- 見つけた未来・プレイ履歴・途中経過は、**その端末のブラウザの中** に保存されます（LocalStorage）
- ページを再読み込みしても、続きから遊べます
- 記録を消したいときは、HOW TO PLAY の画面の一番下にある「記録をすべて消す」を押します

## 開発者向けメモ

### ファイル構成

```
index.html              画面の骨組み（6画面＋説明モーダル）
css/style.css           デザイン（色・文字・レイアウト・アニメーション）
js/engine.js            因果関係シミュレーションエンジン（画面とは無関係・Node でも動く）
js/storage.js           LocalStorage への保存
js/art.js               地球・挿絵・アイコン（すべて SVG）
js/anim.js              アニメーションと DOM の小さな道具
js/sim-view.js          ④ SIMULATION 画面（タイムラインと因果の線）
js/app.js               画面管理と各画面の描画
scenarios/NNN_*.js      シナリオデータ（1ファイル＝1シナリオ）
tests/run-tests.js      全シナリオ・全分岐の自動テスト
tools/build-single.js   1枚の HTML にまとめるスクリプト
```

### エンジンのしくみ

- 各イベントは `eventId / title / description / time / conditions / effects / nextEvents / impactCategory` を持ちます
- プレイヤーの選択（decision）の `next` で最初のイベントが候補になり、イベントが起きるたびに `nextEvents` が候補に加わります
- 候補は **時間の順** に処理され、その時点の「世界の状態」で `conditions` を満たしたものだけが実際に起きます
- 起きたイベントの `effects` で世界の状態（変数・フラグ）が変わり、後のイベントの条件が変わります
- 複数のイベントが同じイベントを `nextEvents` に持つと **合流** し、画面では線が1点に集まります
- ランダム要素はありません。同じ選択なら必ず同じ未来になります
- 比較画面の「別の未来」は、最初の選択だけを変えてエンジンで **計算し直した** 結果です

条件式の書き方：

```
reuse>=3          変数の比較（>= <= > < == !=）
#quiet            フラグが立っている
@b8               イベント b8 がすでに起きた
d1:B              選択 d1 で B を選んだ（d1:AB なら A か B）
!  &&  ||  ( )    否定・かつ・または・かっこ
```

### シナリオの追加方法

1. `scenarios/` にある既存のファイル（例：`008_trash.js`）をコピーして `009_xxx.js` を作る
2. `id`・`number`・`title` を書き換え、選択・イベント・未来を書く
3. `index.html` のシナリオ一覧に `<script src="scenarios/009_xxx.js"></script>` を1行足す
4. `node tests/run-tests.js` を実行して、すべての分岐が最後まで行けるか確認する

テストでは、全分岐について「選択3〜4回」「イベント8件以上」「世界規模の出来事がある」「到達できない未来・起きないイベントがない」「比較できる未来が2つ以上ある」などを確認します。

### 1枚の HTML にまとめる

```
node tools/build-single.js
```

`dist/one-small-choice.html` に、CSS と JavaScript をすべて埋め込んだ1ファイル版ができます。
